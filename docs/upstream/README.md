# Sources utilisées pour l'audit

Les fichiers de ce répertoire sont des copies de sources publiques consultées,
avec leurs commits et chemins dans `manifest.json`. Ils servent à comparer le
protocole documenté au code compilé du simulateur fourni. Ils ne sont pas
compilés ou exécutés par le nouveau pipeline.

La copie de SDClient effectivement utilisée se trouve dans `racing/vendor`,
avec sa licence MIT. Les fichiers du projet d'origine restent inchangés.
